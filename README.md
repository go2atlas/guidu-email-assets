# guidu-email-assets

Imagens usadas nos e-mails da guidu, servidas pelo GitHub Pages:
`https://go2atlas.github.io/guidu-email-assets/<pasta>/<arquivo>`

⚠️ **Repositório PÚBLICO.** Só imagens de e-mail. Nunca subir listas, CSVs,
textos internos ou qualquer dado pessoal.

⚠️ **Não apagar nem renomear arquivos.** E-mails já enviados apontam para estes
endereços; um arquivo removido quebra a imagem na caixa de entrada de quem recebeu.
Para trocar uma imagem, suba com outro nome.

| Pasta | Uso |
|---|---|
| `aulao/` | sequência do Aulão ENEM (out–nov/2026) |
